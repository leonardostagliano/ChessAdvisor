ChessAdvisor ships unmodified Stockfish binaries for Windows x64 in
`resources/engine` (`stockfish-avx2.exe` and `stockfish-popcnt.exe`). They are
downloaded by `scripts/fetch-stockfish.mjs` from the official Stockfish release
assets and are used as a separate process over the UCI protocol; ChessAdvisor
does not link against Stockfish code.

Corresponding source
--------------------
Project page and full source: https://github.com/official-stockfish/Stockfish

by `npm run fetch:stockfish`, which records the release tag, the build commit
URL and the SHA-256 of each downloaded binary.
